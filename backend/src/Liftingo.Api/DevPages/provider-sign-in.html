Provider sign-in (development only)

Signs in at Google or Facebook in this browser and posts the provider token to POST /api/v1/auth/external/{provider}/login. This origin has to be an authorized JavaScript origin of the Google client and an allowed domain of the Facebook app, or their sign-in windows refuse to open.

1. Sign in at the provider

No provider is configured. Set Authentication:Google:ClientId, or Authentication:Facebook:AppId and AppSecret, in the user secrets and restart.
